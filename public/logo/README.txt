# Logo Placeholder Instructions
# ─────────────────────────────────────────────────────────────────────────────
# Place the following official London Kids logo image files in this folder:
#
#   public/logo/logo-primary.png   ← Full-colour logo (for light backgrounds)
#   public/logo/logo-white.png     ← White/reversed logo (for dark backgrounds)
#   public/logo/favicon.png        ← Square icon for browser tab (32×32 px+)
#
# Once the files are placed here:
#   1. Open  src/lib/brand.ts
#   2. Change  PLACEHOLDER_LOGO = true  →  PLACEHOLDER_LOGO = false
#   3. Save the file — all logo references across the site update instantly.
#
# The SchoolLogo component (src/components/SchoolLogo.tsx) handles the switch.
# ─────────────────────────────────────────────────────────────────────────────
